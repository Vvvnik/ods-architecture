# UI-контракт: экран «Граф» (006)

**Спека**: [spec.md](../spec.md)  
**Потребитель**: `specs/003-portal-mvp` (замена `GraphStubPage`)  
**API**: [openapi-graph.yaml](./openapi-graph.yaml)

## Маршрут

`/graph` — пункт навигации «Граф» (уже есть в `003`, заменить содержимое страницы).

## Предусловия

- Выбран проект в workspace (как для дерева файлов).
- Для данных графа нужен завершённый анализ (`005`) с успешным ingest (`006`).

## Макет `GraphPage`

```text
┌─────────────────────────────────────────────────────────┐
│ Граф зависимостей          [Снимок: run … ▼] (опц.)   │
├──────────────────┬──────────────────────────────────────┤
│ Узлы (список)    │ Рёбра выбранного узла               │
│ path / kind /    │ from → to | type | path              │
│ name             │                                      │
│ [пагинация]      │                                      │
└──────────────────┴──────────────────────────────────────┘
```

**Компоненты:**

| Компонент | Назначение |
|-----------|------------|
| `GraphPage` | layout, загрузка summary + nodes |
| `NodeList` | `GET .../graph/nodes`, клик → выбор узла |
| `EdgeTable` | `GET .../graph/nodes/{id}/edges` |
| `GraphEmptyState` | нет анализа / нет данных |
| `FileGraphPanel` | опционально: при выборе файла в дереве — `.../files/{path}/dependencies` |

## Загрузка данных

1. `GET /projects/{id}/graph/summary` — если 404 → `GraphEmptyState`.
2. `GET /projects/{id}/graph/nodes?limit=50&offset=0` — список.
3. При выборе узла — `GET .../graph/nodes/{nodeId}/edges?direction=both`.

Пагинация узлов: кнопки «Далее» / «Назад» (`offset` += `limit`).

## Пустые состояния (русский)

| Ситуация | Заголовок | Текст | Действие |
|----------|-----------|-------|----------|
| Нет анализа | «Граф недоступен» | «Сначала выполните синхронизацию и анализ кода.» | ссылка на workspace / sync |
| Ingest failed | «Ошибка построения графа» | «Не удалось преобразовать результаты анализа.» | повторить анализ |
| Нет узлов | «Граф пуст» | «В проекте не найдены символы для отображения.» | — |

## Интеграция с деревом файлов

При клике на файл в `WorkspacePage` (опционально v1.1):

- боковая панель или вкладка «Зависимости файла»
- `GET .../graph/files/{path}/dependencies`
- компактный список узлов + рёбер (без полного `GraphPage`)

MVP: достаточно отдельного `/graph`; панель — если время в tasks.

## Ограничения (не входит)

- React Flow, drag-and-drop layout, zoom canvas
- Редактирование графа
- Экспорт GraphML / DOT
- Показ raw `model` из envelope

## Сообщения ошибок API

Отображать `message` из `ApiError` как есть (русский, FR-014).

Примеры:

- `graph_not_found` → «Граф для проекта ещё не построен»
- `analysis_run_not_found` → «Указанный прогон анализа не найден»

## Доступность

- Списки — семантические `<table>` или `role="grid"` для рёбер
- Клавиатурная навигация по списку узлов (стрелки / Enter)

## Замена заглушки

Удалить или заменить `GraphStubPage` на `GraphPage` в роутере `003`.
Текст заглушки «Граф зависимостей (скоро)» больше не показывается.
