# Видение проекта

> **Спецификации (Spec Kit):**

> - Этап 1 — модель данных MVP: [`specs/002-domain-model/spec.md`](../../specs/002-domain-model/spec.md)
> - Этап 2 — портал MVP: [`specs/003-portal-mvp/spec.md`](../../specs/003-portal-mvp/spec.md)

Черновик идей (источник для спек):

1. Создать фронтенд и backend приложение для анализа исходного кода в виде микросервиса плюс БД для хранения структуры рабочей копии репозиториев с возможность удаления самих исходных данных с хранением только извлеченных метаданных, хранения метаданных для графа зависимостей, и векторной базы данных для RAG - elasticsearch.
2. Они должны быть написаны на TypeScript в виде микросервиса с возможностью развертывания в Docker контейнере и на .NET с возможностью развертывания в Docker контейнере или оба в одном контейнере.
3. Фронтенд реализует отображение и взаимодействие с пользователем, backend сервис реализует логику анализа исходного кода и взаимодействие с БД.
4. бэкенд в дальнейшем не включается в мвп будет узнавать языки проекта исходного кода и подключать соответствующие парсеры / анализаторы исходного кода например Рослин TS AST и другое.
5. Формат хранения структуры рабочей копии репозиториев и метаданных для графа зависимостей и векторной базы данных для RAG - elasticsearch должен быть JSON.
6. Структура и формат хранения данных — в [`specs/002-domain-model/spec.md`](../../specs/002-domain-model/spec.md).
7. UI, меню, панели — в [`specs/003-portal-mvp/spec.md`](../../specs/003-portal-mvp/spec.md).
